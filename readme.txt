== Changelog ==

[ 開発環境 ] template-parts/breadcrumb.php の関数定義が二重読み込みに耐えられず、書類一覧の index.php を検証する PHPUnit テストが書けない不具合を修正

1.14.0
[ 機能追加 ] 書類の閲覧に必要な権限を変更できる bill_vektor_can_view_documents フィルターを追加（購読者など閲覧専用のアカウントにも従来どおり表示したい場合に使用）
[ 機能追加 ] 請求書一覧画面に取引先名を表示するカラムを追加
[ 仕様変更 ] 請求書・見積書の閲覧に書類の編集権限（寄稿者以上）を必須に変更し、権限のないログインユーザーには案内ページを表示
[ 不具合修正 ] 取引先が未設定の書類で、取引先名の表示箇所（書類本体・PDFのファイル名・CSVエクスポート・書類一覧）に書類自身の件名が表示される不具合を修正
[ 不具合修正 ] 取引先（登録済）に不正な値が保存されている書類で、無関係な投稿のタイトルが取引先名として表示され、その投稿へのリンクが表示される不具合を修正
[ 不具合修正 ] 書類一覧をスクリーンリーダーで読み上げた際に、取引先が未設定の欄やページ送りの見出しが読み上げられない不具合を修正
[ 不具合修正 ] 書類一覧・取引先一覧の「書類」列のリンク先取得を誤っており、リンクをクリックしても画面が遷移しない不具合を修正
[ 不具合修正 ] 書類一覧の絞り込み（投稿タイプ・取引先・発行日）に配列を渡すと、PHP の警告（Array to string conversion）がログに記録される不具合を修正
[ 不具合修正 ] 書類・取引先のカスタムフィールドで保存確認に使うnonceが編集画面を開いてから一定時間が経過すると無効化される作りになっており、時間を空けて更新するとエラー表示なく保存内容が反映されない不具合を修正
[ 不具合修正 ] 投稿の更新時に作成される変更履歴（リビジョン）にも請求品目のカスタムフィールドの値が書き込まれ、不要なデータが保存され続ける不具合を修正
[ セキュリティ修正 ] フロント側の閲覧制限がログインの有無しか見ておらず、購読者など権限のないログインユーザーに請求書・見積書の一覧や明細（金額・取引先・振込口座）を閲覧されてしまう問題を修正
[ セキュリティ修正 ] フロント側の閲覧制限の判定方法に問題があり、管理画面用の機能をフロント側で使うプラグインと併用すると制限が無効化され、ログインしていない第三者に請求書・見積書を閲覧されてしまう問題を修正
[ セキュリティ修正 ] REST API の閲覧制限に書類の閲覧権限の確認を追加
[ セキュリティ修正 ] カスタムフィールドの保存処理に、投稿の編集権限があることの確認を追加

1.13.0
[ 機能追加 ] 見積書一覧画面に取引先名を表示するカラムを追加
[ 機能追加 ] 書類一覧の絞り込み検索に「キーワード」の入力欄を追加（書類の件名を対象に検索。CSVエクスポートの抽出条件にも反映）
[ 仕様変更 ] 書類一覧の絞り込み検索の「絞り込み」ボタンを「発行日」の下へ移動し、横幅いっぱいの表示に変更
[ 不具合修正 ] 管理画面用CSSの読み込みURLにバージョンのクエリ文字列が付与されておらず、テーマを更新しても古いCSSがブラウザキャッシュから読み込まれる不具合を修正
[ デザイン不具合修正 ] 絞り込み検索が狭い画面幅で1カラムに折り返されず、入力欄が重なって操作できなくなる不具合を修正
[ セキュリティ修正 ] CSVエクスポートに権限チェックとCSRF検証がなく、ログインしていない第三者に請求書データを取得されてしまう問題を修正
[ セキュリティ修正 ] REST APIにログインチェックがなく、ログインしていない第三者に請求書の件名・発行日やユーザー名を取得されてしまう問題を修正
